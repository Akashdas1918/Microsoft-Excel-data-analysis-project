# 📊 Excel Minor Project – Sales Data Analysis

## 📌 Project Overview

This project is a hands-on **Microsoft Excel data analysis project** focused on analyzing sales-related datasets and extracting useful business insights.

The project contains **30 questions across 5 major areas**, covering lookup functions, data cleaning, conditional aggregation, pivot analysis, and advanced Excel functions.

---

## 🎯 Objectives

* Practice Excel formulas and functions using structured datasets
* Perform data cleaning and quality checks
* Retrieve information from multiple related datasets
* Perform conditional calculations and aggregations
* Analyze data using Pivot Tables
* Extract meaningful business insights from sales data
* Improve practical Excel and data-analysis skills

---

## 🗂️ Datasets

The project uses the following datasets:

* **Orders** – transaction/order-level information
* **Customers** – customer details
* **Products** – product and category information
* **Sales_Reps** – sales representative information
* **Targets** – sales targets

---

## 📚 Project Sections

### 1. Lookup Functions

Practiced functions such as:

* `VLOOKUP`
* `INDEX`
* `MATCH`

Used these functions to retrieve customer, product, sales representative, region and target information from related datasets.

### 2. Data Cleaning

Worked on common data-quality tasks such as:

* Identifying missing values
* Checking duplicate records
* Standardizing inconsistent values
* Checking data formats
* Identifying invalid records
* Preparing data for analysis

### 3. Conditional Aggregation

Applied functions including:

* `SUMIF`
* `SUMIFS`
* `COUNTIF`
* `AVERAGEIF`
* `AVERAGEIFS`
* `MAX`
* `MIN`

These were used to calculate sales-related metrics based on different conditions.

### 4. Pivot Analysis

Used Excel Pivot Tables to analyze:

* Sales by region
* Sales by product/category
* Sales by sales representative
* Top-performing products
* Monthly sales trends
* Sales versus targets

### 5. Advanced Excel Analysis

Applied advanced formulas and combinations of functions to answer more complex business questions, including:

* Multi-condition analysis
* Duplicate detection
* Dynamic lookups
* Minimum/maximum analysis
* Sales comparisons
* Business-performance calculations
